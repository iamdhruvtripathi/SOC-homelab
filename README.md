# SOC Homelab

A hands-on Security Operations Center (SOC) homelab built using Wazuh, Sysmon and an Active Directory environment to simulate enterprise security monitoring. The lab focuses on centralized log collection, endpoint visibility, event correlation, and threat detection through the Wazuh Dashboard

## Project Background

Modern Windows environments generate a vast amount of security telemetry that can reveal indicators of compromise when properly monitored. This project demonstrates how Sysmon enhances Windows logging and how Wazuh collects, correlates, and analyzes those events within an Active Directory environment. The result is a realistic platform for practicing SOC workflows, investigating alerts, and analyzing security events in a safe, isolated lab
